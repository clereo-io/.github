## Clereo

Clereo checks a company's public security every day, from the outside, and turns the results into a Trust Profile its customers can read. Every result shows how it was checked.

- [clereo.io](https://clereo.io)
- [How each check works](https://clereo.io/methodology)
- [Blog](https://clereo.io/blog)

### Here

- [security-fixes](https://github.com/clereo-io/security-fixes): copy-paste fixes for common website and email security findings (DMARC, SPF, security.txt, CSP and security headers for nginx, Apache, Cloudflare, Vercel and Netlify).

Found a security issue in Clereo? See [clereo.io/.well-known/security.txt](https://clereo.io/.well-known/security.txt).
